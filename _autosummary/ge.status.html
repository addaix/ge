ge.status¶

GitHub’s native issue statuses: read, set and search them.

GitHub issues carry a status (public preview since 2026-11-23): one of a fixed set, each in a category that decides whether the issue is open or closed.

Setting a closed status closes the issue and setting an open one reopens it, so the status is the single field to write. GitHub also moves it on its own: assigning a person moves Backlog to Todo, linking a draft PR moves it to In progress, linking an open PR (or marking the draft ready) moves it to In review, closing moves it to Done, and reopening resets it to Backlog.

Everything goes through the gh CLI (REST status field; GraphQL only for Duplicate, which needs the original issue). Where statuses are not available (the preview has not reached that repository, or the viewer cannot see them), issue_status() returns None and callers fall back on open/closed.

>>> normalize_status('in-progress')
'In progress'
>>> normalize_status('TODO')
'Todo'
>>> status_query('In progress')
'status:"In progress"'

ge.status.normalize_status(name, *, statuses=('Backlog', 'Todo', 'In progress', 'In review', 'Done', 'Not planned', 'Duplicate'))[source]¶

Return the exact status name GitHub expects for a loosely spelled one.

Case, hyphens and underscores are ignored (in-progress, NOT_PLANNED).

>>> normalize_status('not_planned')
'Not planned'
>>> normalize_status('doing')

ge.status.set_issue_status(repo, number, status, *, duplicate_of=None, statuses=('Backlog', 'Todo', 'In progress', 'In review', 'Done', 'Not planned', 'Duplicate'))[source]¶

Set an issue’s status; GitHub closes or reopens it to match.

Returns {'number', 'state', 'state_reason', 'status'} as GitHub now reports them. Duplicate needs duplicate_of (the original issue’s number in the same repository). Raises RuntimeError when GitHub did not apply it (issue statuses unavailable in that repository).

Setting an open status on a closed issue reopens it: check the state first if that is not what you want.

>>> # set_issue_status('owner/repo', 42, 'In progress')
Return type:

dict
